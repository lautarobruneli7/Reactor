# Preguntas para validar el enfoque

Para conversar con una persona que trabaje en laboratorio. Las cinco primeras son las que más cambian el diseño.

1. **Indicadores de calidad:** ¿qué indicadores le resultarían más útiles en el trabajo diario del laboratorio? (hoy: rendimiento, pureza y balance estequiométrico)
2. **Síntesis o formulación:** ¿tiene más sentido enfocarlo en la síntesis (reacciones) o en la formulación (mezcla de ingredientes ya producidos)?
3. **Fuentes de datos:** ¿qué fuentes confiables usaría para propiedades, especificaciones y rendimientos? ¿Hay farmacopeas o bases a las que tenga acceso?
4. **Educativo o profesional:** ¿lo ve como herramienta educativa o como apoyo profesional? Esto define cuánta validación de datos hace falta.
5. **Errores inaceptables:** ¿qué errores o simplificaciones del modelo serían inaceptables para alguien del área?

## Para revisar el modelo actual

6. ¿Qué ruta de síntesis del ibuprofeno conviene modelar y con qué pasos y coeficientes? (ver `supuestos-del-modelo.md`)
7. ¿Qué parámetros de calidad se controlan en la práctica (impurezas específicas, pérdida por secado, residuos de solventes, etc.)?
8. ¿Qué otros productos serían buenos candidatos para sumar después del ibuprofeno?
9. ¿Qué datos necesitaría ver en pantalla para confiar en un resultado?
